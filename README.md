# Program Rekap dan Analisis Nilai Matematika Siswa

## Deskripsi
Program sederhana berbasis Python untuk membantu guru mengelola dan menganalisis nilai matematika siswa secara lebih terstruktur.

## Fitur Utama
1. Memasukkan nama dan nilai siswa.
2. Menampilkan data nilai siswa.
3. Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
4. Menentukan status ketuntasan berdasarkan KKM.
5. Menyimpan data hasil pengolahan ke dalam file.

## Ketentuan Program
- Rentang nilai: 0–100.
- Kriteria Ketuntasan Minimal (KKM): 75.
- Bahasa pemrograman: Python.
- Media: Terminal atau console.
